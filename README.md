# Butterfly Effect

One small decision. A thousand unexpected consequences.

An AI-assisted decision simulation lab, starting with university parking and transportation planning.
All numbers are illustrative estimates from hypothetical data, not real Cal Poly measurements.

## Status
Stage 1 of 6: foundation and dashboard (placeholders for map, network and metrics).

## Run it
1. Install Node.js (version 18 or newer) from https://nodejs.org
2. In this folder run: `npm install`
3. Then run: `npm run dev`
4. Open the address it prints, usually http://localhost:5173

## Check that it builds
`npm run build` should finish with no errors.

## Deploy
Push to GitHub, then import the repository in Vercel. Vercel detects Vite automatically.
